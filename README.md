# Fluid Particle Resonance

一个基于 Processing 的交互式流体粒子共鸣场艺术作品。

## 功能特点

- 流体粒子系统，基于 Perlin Noise 驱动
- 鼠标交互：引力/斥力模式、发光效果
- 多层粒子：前景粒子 + 背景粒子 + 鼠标轨迹
- 粒子连接线网络
- 支持保存高清截图

## 交互说明

| 操作 | 效果 |
|------|------|
| 鼠标移动 | 产生引力/斥力场 |
| 鼠标拖动 | 留下粒子轨迹 |
| 鼠标点击 | 产生粒子爆发 |
| 按键 1 | 切换引力/斥力模式 |
| 按键 2 | 显示/隐藏连接线 |
| 按键 3 | 重置粒子系统 |
| 按键 s | 保存截图 |

## 运行要求

- Processing 4.x (Java 模式)
- Windows / macOS / Linux
